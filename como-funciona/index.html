Como funciona

Da primeira telemetria ao resultado de uma ação.

Um ciclo contínuo de coleta, visibilidade e gerenciamento. Explore cada etapa da comunicação entre as máquinas e o A.D.A.M.

Agent Python

Executado em segundo plano, coleta CPU, RAM, disco, rede, processos e atividade. Envia telemetria periodicamente, consulta comandos e devolve os resultados da execução local.

02 / 06

Fluxo conceitual dos dados. Agents e dashboard se comunicam com o servidor; não acessam o banco diretamente.

01
MONITORAMENTO

O Agent inicia com o computador

Em cada estação Windows, o Agent Python é executado em segundo plano para acompanhar a máquina.

02
MONITORAMENTO

O Agent registra-se no servidor

O registro permite identificar o computador e associá-lo ao ambiente gerenciado.

03
MONITORAMENTO

A telemetria é enviada periodicamente

CPU, memória, armazenamento, rede, processos e atividade seguem para o servidor por REST/HTTP.

04
MONITORAMENTO

O servidor armazena e processa os dados

FastAPI recebe as informações; SQLAlchemy e SQLite dão suporte à persistência dos registros.

05
MONITORAMENTO

O dashboard apresenta as informações

Pelo navegador, o responsável acompanha status, métricas e eventos dos computadores cadastrados.

06
GERENCIAMENTO

O administrador seleciona uma máquina

A organização por laboratório e posição ajuda a encontrar uma estação ou selecionar um grupo.

07
GERENCIAMENTO

O administrador solicita um comando

A ação parte do dashboard e passa pela validação do sistema antes de entrar na fila.

08
GERENCIAMENTO

O Agent consulta e recebe o comando

O Agent consulta o servidor periodicamente e recebe os comandos destinados à sua máquina.

09
GERENCIAMENTO

Python executa a ação localmente

A execução acontece no computador, pelo Agent Python, e não diretamente pela IA.

10
GERENCIAMENTO

O resultado retorna ao servidor

O servidor recebe o resultado e o dashboard permite acompanhar a conclusão e o histórico.
